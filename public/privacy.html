1. Кто мы

Приложение AvtoEmir предназначено для учеников автошколы: регистрация, загрузка документов, теория ПДД, тесты, запись на вождение и связь с администрацией.

2. Какие данные собираем

  • Имя и номер телефона при регистрации
  • Загруженные документы заявки: сканы / фото удостоверения личности, медицинских и иных справок
  • Прогресс теории и результаты тестов
  • Сообщения в чате с администрацией / инструктором
  • Технические данные работы приложения (сессия входа)

3. Зачем используем

Для работы автошколы: проверка документов, обучение, запись на занятия, поддержка учеников. Данные не используются для рекламы третьих лиц.

4. Передача третьим лицам

Мы не продаём персональные данные. Хостинг и облако (Vercel, Supabase) используются только для работы сервиса. Документы видит администрация автошколы при проверке заявки.

5. Хранение, передача и защита документов

Передача. Все данные, включая сканы документов, передаются только по HTTPS (TLS). Незащищённый HTTP для загрузки не используется.

Хранение. Файлы — в Supabase Storage, сведения о заявке — в базе Supabase. У провайдера включено шифрование при хранении (encryption at rest).

Пароли. Хранятся в виде криптографического хеша, не открытым текстом.

Доступ. Документы доступны ученику и администрации автошколы.

6. Удаление данных

Удалите аккаунт в приложении AvtoEmir или отправьте запрос на странице удаления. Связанные данные и документы заявки будут удалены из рабочих систем сервиса.
